## Error Resolution

### Problem Reported
```
"failed to send request to the edge function (status: unknown)"
```

### Root Cause
Frontend components were calling `supabase.functions.invoke('arbitrage-scanner')` which no longer exists in Supabase because the function was migrated to the VPS API.

### Solution Applied
Updated all frontend calls from:
```typescript
supabase.functions.invoke('arbitrage-scanner', {...})
```

To:
```typescript
fetch('http://localhost:3001/functions/arbitrage-scanner', {...})
```

### Verification
- ✅ No more `supabase.functions.invoke()` calls (except RLS functions)
- ✅ All calls now use `fetch()` to VPS API
- ✅ JWT token authentication working
- ✅ Environment variable correctly pointing to API

## System Architecture

### Data Flow

```
User Browser
    ↓
React Components (Frontend)
    ├─ ArbitrageScanner.tsx
    ├─ ArbitrageOpportunityCard.tsx
    └─ TradeRecoveryPanel.tsx
    ↓
fetch() → http://localhost:3001/functions/*
    ↓
VPS API (Express.js)
    ├─ Validate JWT token
    ├─ Process request
    └─ Query database
    ↓
Supabase PostgreSQL
    ↓
Response back to Frontend
```

### Authentication

All requests include JWT Bearer token:
```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

Token is:
- Generated by Supabase at login
- Valid for ~60 minutes
- Contains user ID and role
- Verified on each API request

## Support & Troubleshooting

### Common Issues

**Issue**: "Connection refused" error
- **Cause**: VPS API not running
- **Solution**: `cd services/api && npm run dev`

**Issue**: "401 Unauthorized" error
- **Cause**: Invalid JWT token
- **Solution**: Log out and log back in

**Issue**: "CORS error" in browser console
- **Cause**: CORS not configured
- **Solution**: Check services/api/src/index.ts for CORS settings

**Issue**: "Endpoint not found" error
- **Cause**: VPS API URL incorrect
- **Solution**: Check `VITE_FUNCTIONS_URL` in .env

### Debug Commands

```bash
# Check if API is running
curl http://localhost:3001/health

# Check environment variable
grep "VITE_FUNCTIONS_URL" .env

# Search for any remaining Supabase function calls
grep -r "supabase.functions.invoke" src/components

# Watch API logs
cd services/api && npm run dev
```
